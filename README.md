# Glint

Расширение для Twitch, которое само собирает бонусные баллы канала, моменты и дропы, не даёт стриму встать на паузу в фоновой вкладке и показывает, сколько вы заработали.

Работает в Chrome, Яндекс Браузере, Edge, Opera, Brave и других браузерах на Chromium (версия 111 и новее). Manifest V3.

## Возможности

- **Баллы канала.** Нажимает на сундук с бонусом, как только он появляется. Сумма записывается в статистику.
- **Моменты.** Забирает памятные моменты во время стрима.
- **Дропы.** Пока открыт хотя бы один стрим, открывает инвентарь в фоновой вкладке, получает готовые дропы и закрывает вкладку. Раз в 15 минут, а если дропов нет, реже, до раза в час.
- **Списки каналов.** Собирать везде, только на выбранных каналах или везде, кроме выбранных.
- **Самопроверка.** Если Twitch изменил сайт и кнопки перестали находиться или нажиматься, в окне расширения появляется предупреждение. Сбор записывается в статистику только после того, как страница его подтвердила.
- **Плеер.** Стрим не останавливается и не теряет качество в фоновой вкладке. После ошибки плеера расширение нажимает «Повторить», а если ошибка повторяется, перезагружает страницу. Предупреждение 18+ пропускается.
- **Статистика.** Баллы за сегодня, график за 7 дней, лучшие каналы, история событий, счётчик на значке.
- **Уведомления.** Плашка на странице Twitch, системные уведомления о дропах и моментах.
- **Приватность.** Нет серверов, аналитики и рекламы. Все данные хранятся только в браузере, их можно скачать в JSON.
- **Языки:** русский и английский. Светлая и тёмная тема подстраиваются под систему.

## Установка из папки

1. Откройте `chrome://extensions` (в Яндекс Браузере `browser://extensions`).
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите эту папку (ту, где лежит `manifest.json`).

## Публикация

Готовый архив для Chrome Web Store собирается так:

```sh
npm run pack   # или: python3 tools/pack.py
```

Он появится в `dist/glint-<версия>.zip`. Для страницы в магазине понадобятся:

- описание (можно взять из раздела «Возможности»);
- скриншоты 1280×800: `npm run store` создаёт их на русском и английском в `tools/out/store/`;
- ссылка на политику конфиденциальности (`PRIVACY.md`, её можно опубликовать, например, через GitHub Pages);
- обоснование разрешений:
  - `storage`: настройки и статистика;
  - `alarms`: периодическая проверка дропов;
  - `notifications`: уведомления о дропах и моментах;
  - доступ к `www.twitch.tv`: работа на страницах Twitch.

Glint не связан с Twitch и не одобрен Twitch. Автоматизация действий может противоречить правилам Twitch. Пользуйтесь на своё усмотрение.

## Как устроено

| Файл | Что делает |
|---|---|
| `src/background.js` | Service worker. Записывает собранное в статистику, проверяет дропы по расписанию, обновляет значок и показывает уведомления. |
| `src/content/content.js` | Работает на страницах Twitch: ищет кнопки бонуса, моментов и дропов, следит за плеером, показывает плашки. |
| `src/content/page.js` | Работает в контексте самой страницы. Сообщает Twitch, что вкладка видима. |
| `src/popup/` | Окно расширения: обзор, история, настройки. |
| `src/shared/defaults.js` | Настройки по умолчанию и общие функции. |
| `_locales/` | Переводы. |

Twitch часто меняет вёрстку. Если что-то перестало находиться, поправьте селекторы в функциях `findBonusButton`, `claimMoments` и `claimDrops` в `src/content/content.js`.

## Разработка

```sh
npm install      # инструменты для тестов (само расширение сборки не требует)
npm run check    # проверка синтаксиса
npm test         # автотест в Chromium + скриншоты попапа в tools/out/
npm run icons    # пересобрать PNG-иконки из icons/icon.svg
npm run store    # скриншоты 1280×800 для Chrome Web Store
```
